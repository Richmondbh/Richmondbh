## Featured project: Library Management API

A **production-ready .NET 9 Web API**, redesigned from my earlier BookCollection API using Clean Architecture and CQRS. The application was hosted on Azure, tested, and received positive feedback from experienced developers.

- Clean Architecture with Domain, Application, Infrastructure and API layers; CQRS with MediatR.
- JWT role-based authorization, FluentValidation, logging and Redis caching.
- PostgreSQL with EF Core 9; Azure Service Bus, Functions and Blob Storage.
- Application Insights, Docker Compose and GitHub Actions CI/CD.
- **65+ unit and integration tests.**

This personal project demonstrates backend architecture, cloud integration and tested software delivery.
